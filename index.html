1. เชื่อมต่อ Google Sheets

นำ Excel เข้า Google Sheets แล้วรัน setup ใน Apps Script

วิธีติดตั้งโดยย่อ
  1. นำเข้า RainGarden.xlsx แล้วบันทึกเป็น Google Sheets
  2. ส่วนขยาย → Apps Script → วาง Code.gs
  3. เลือกฟังก์ชัน setup → Run → อนุญาตสิทธิ์
  4. Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone
  5. คัดลอก URL และรหัสจากเมนู “เลขาสวนยาง” มาใส่ด้านบน

2. ยืนยันตำแหน่งสวน

ใช้พิกัดจริงของสวน ไม่ใช่ตำแหน่งปัจจุบันหากคุณอยู่ที่บ้าน

เปิดแผนที่ตรวจตำแหน่ง ↗

3. ตั้งเวลาล่วงหน้าและเกณฑ์เตือน

เมื่อเชื่อมข้อมูลเรดาร์เชิงตัวเลข ระบบจะเตือนทั้งระยะ 5 กม.และเวลาถึงตามที่ตั้งไว้

4. ช่องทางแจ้งเตือน

Telegram: ใส่ TELEGRAM_BOT_TOKEN และ TELEGRAM_CHAT_ID ใน Script Properties แล้วกดทดสอบส่ง ข้อมูลลับไม่เก็บใน HTML

ไฟล์ HTML ไม่สามารถส่งเสียงเมื่อปิดหน้าเว็บหรือถูกมือถือพักการทำงาน ใช้อีเมล / Telegram เป็นช่องทางเบื้องหลัง
